# Projeto_Porta_Logica
Landing page tech-minimalista sobre eletrônica digital. Possui um laboratório interativo em tempo real onde o usuário alterna entre as portas lógicas AND, OR, NOT e XOR e manipula as entradas binárias (0 e 1). O sistema calcula a saída e destaca a tabela verdade instantaneamente, unindo teoria e prática de forma fluida.
