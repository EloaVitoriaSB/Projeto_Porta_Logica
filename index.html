O que são Portas Lógicas?

Portas lógicas são circuitos eletrônicos integrados que tomam decisões com base em sinais elétricos (0 para desligado, 1 para ligado). Combinando bilhões delas, criamos processadores funcionais.

Álgebra Booleana

A matemática por trás do binário, inventada por George Boole para processar verdadeiro ou falso.

Tabela Verdade

O mapa completo de um circuito que mostra exatamente qual será a saída para cada combinação de entrada.

Sinais Digitais

A linguagem das CPUs. Transistores operando como interruptores ultrarrápidos de ligar e desligar.

Catálogo de Componentes

Fichas técnicas detalhadas das quatro portas lógicas fundamentais.

Porta AND (E)

S = A · B

Age como uma multiplicação matemática binária. É usada em circuitos onde critérios de segurança triplos ou duplos precisam ser validados antes de ligar um motor ou liberar um acesso.

Porta OR (OU)

S = A + B

Representa uma soma lógica. Se pelo menos um dos caminhos tiver energia, a saída é ligada. É o padrão utilizado em centrais de alarmes conectados a múltiplos sensores de janelas.

Porta NOT (Inversora)

S = Ā

Inverte o sinal. Possui apenas uma entrada. Essencial para criar memórias computacionais (Flip-flops) e alternadores de pulsos automáticos dentro de relógios digitais.

Porta XOR (Exclusiva)

S = A ⊕ B

Sua saída é verdadeira apenas se as duas entradas forem diferentes entre si. É a base matemática exata para a criação de circuitos somadores aritméticos de calculadoras e computadores.
